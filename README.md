# Cloud Platform Learning

Hands-on learning repository for my transition toward cloud, platform, Kubernetes, and MLOps engineering.

## Learning path

1. Linux, Bash, Python, and Ansible
2. Containers and Docker
3. Kubernetes administration
4. Cloud infrastructure and Terraform
5. Machine-learning fundamentals
6. MLOps and AI workloads on Kubernetes

## Repository structure

```text
linux/       Linux administration and Bash labs
python/      Python exercises and automation
containers/  Container and Docker labs
kubernetes/  Kubernetes manifests and operational labs
cloud/       Cloud-provider exercises
terraform/   Infrastructure-as-code exercises
ansible/     Configuration-management exercises
mlops/       MLOps and AI-platform exercises
notes/       Study notes and references
```

## Working method

- Prioritize hands-on work over passive course consumption.
- Keep each lab reproducible and document the commands and outcome.
- Never commit passwords, tokens, private keys, or environment secrets.
- Use a separate branch for larger exercises and changes.

## Environment

- Windows with WSL 2
- Ubuntu 24.04 LTS
- Git and GitHub over SSH
- Python 3 with isolated virtual environments
- Visual Studio Code with WSL integration
